# 02-CONNECTIONS · ideas que salieron de cruzar dos o más notas

Aquí no van capturas: va lo que emergió de la relación entre ellas. Cuatro tipos valen: mismo principio en dos dominios, dos notas que se contradicen, patrón en tres o más notas, una pregunta que otra nota responde por accidente.
Las escribe el tejedor (o tú en el ritual diario) y cada una enlaza sus notas fuente con [[Título]].
Qué NO va: una captura cruda ni una conexión obvia.
Error fácil: meter aquí una nota nueva «porque es interesante». Si no cruza dos notas, es una captura.
Ejemplo: `2026-09-28-entropia-deuda-tecnica.md` — tipo A, puente en una frase, entrada posible.
