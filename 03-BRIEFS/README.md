# 03-BRIEFS · la cola de producción

Cada archivo es una pieza lista para escribir: ONE THING, PROOF, READER TRANSFORMATION, tres entradas y tres cierres, con las notas fuente enlazadas.
Los borradores del escriba viven aquí también, junto al brief, con sufijo -borrador.md.
Qué NO va: ideas sueltas (02-CONNECTIONS) ni piezas ya publicadas (04-PUBLISHED).
Ejemplo: `2026-09-28-entropia-deuda-tecnica.md` con etiqueta listo-para-escribir.
