# 04-PUBLISHED · lo publicado, con sus números pegados

Lo que ya salió, con impresiones, guardados y el comentario que más se repitió en el frontmatter. De aquí sale la revisión mensual y la cosecha de voz.
Regla dura: el TEXTO de una nota publicada no se edita nunca; solo se actualizan las métricas. Un hook lo bloquea.
Qué NO va: borradores (03-BRIEFS).
Ejemplo: `2026-10-05-entropia-deuda-tecnica.md` con `impresiones: 4200, guardados: 268`.
