# 06-PROYECTOS · un proyecto por carpeta

Cada proyecto de código o app tiene aquí su carpeta con: `plan.md` (del programador, fase de arquitectura), `decisiones.md` y el enlace a su repositorio y su rama.
El código NO vive aquí: vive en su propio repositorio, siempre en una rama claude/… hasta que tú hagas merge.
Regla dura: nunca se crea un repositorio, servicio ni despliegue nuevo sin tu «sí» escrito.
Ejemplo: `app-recetas/plan.md`, `app-recetas/decisiones.md`.
